Tổng quan

Hệ thống tự động forward email từ Gmail sang Discord channel thông qua Google Cloud Pub/Sub push notifications.

Flow hoạt động:
Gmail nhận email mới → Google Pub/Sub push → Firebase Function xử lý → Filter Rules đánh giá → Discord Bot gửi embed message (~2-5 giây)
Thành phầnMô tảYêu cầu
Gmail AccountAccount cần theo dõi emailBắt buộc
Discord BotBot gửi message vào channelBắt buộc
Discord ChannelChannel nhận email notificationsBắt buộc
Filter RulesLọc email nào forward/bỏ quaTùy chọn

Bước 1: Tạo Discord Bot

1 Truy cập https://discord.com/developers/applications

2 Click "New Application" → đặt tên (vd: "Email Forwarder") → Create

3 Vào tab "Bot" bên trái sidebar

4 Click "Reset Token" → Copy token

5 Tắt "Public Bot"

6 Bật "Message Content Intent"

⚠️ Quan trọng: Bot Token chỉ hiện 1 lần duy nhất. Hãy copy và lưu ngay. Nếu mất, phải Reset Token tạo mới.

Bước 2: Invite Bot vào Server

1 Trong Discord Developer Portal, vào tab "OAuth2" → "URL Generator"

2 Mục Scopes: tick bot

3 Mục Bot Permissions: tick Send Messages và Embed Links

4 Copy Generated URL ở dưới → paste vào browser

5 Chọn server → Authorize

Bước 3: Lấy Channel ID

1 Mở Discord app → Settings → Advanced → bật "Developer Mode"

2 Right-click vào channel muốn nhận email → "Copy Channel ID"

💡 Tip: Nên tạo channel riêng cho email notifications (vd: #email-alerts) để không lẫn với chat thường.

Bước 4: Config trong App

1 Vào Discord Settings trong app

2 Tab "Bot Config":

  • Dán Bot Token vào ô Bot Token
  • Dán Channel ID vào ô Channel ID
  • Click "Save Config"

3 Click "Test Connection"

✅ Thành công: Bạn sẽ thấy message test xuất hiện trong Discord channel. Nếu không thấy, kiểm tra lại Bot Token và Channel ID.

Bước 5: Setup Gmail Watch

⚙️ Yêu cầu GCP (Admin setup 1 lần):
Trước khi dùng Gmail Watch, admin cần setup trên Google Cloud Console:
  1. Enable Gmail API cho project
  2. Tạo Pub/Sub topic: gmail-notifications
  3. Cấp quyền Pub/Sub Publisher cho gmail-api-push@system.gserviceaccount.com
  4. Deploy Firebase Functions

1 Vào Discord Settings → tab "Watch Status"

2 Click "Start" cho Gmail account muốn theo dõi

3 Status chuyển thành "Active" (badge xanh)

StatusÝ nghĩaHành động
🟢 ActiveĐang theo dõi email mớiCó thể Stop
🟡 ExpiringSắp hết hạn (<24h)Tự động renew 2AM UTC
⚪ ExpiredĐã hết hạnClick Start lại
🔴 ErrorLỗi renewalKiểm tra token, Start lại

Bước 6: Tạo Filter Rules

1 Vào Discord Settings → tab "Filter Rules"

2 Click "Add Rule"

3 Điền thông tin rule → "Save"

Các trường của Rule

TrườngMô tảGiá trị
NameTên ruleTên mô tả (vd: "Boss emails")
FieldTrường email cần checkFrom / Subject / Label
OperatorCách so sánhEquals / Contains / Starts with / Regex
ValueGiá trị cần matchText hoặc regex pattern
LogicKhi có nhiều conditionsAll (AND) / Any (OR)
ActionHành động khi matchForward / Ignore
PriorityThứ tự đánh giáSố nhỏ = đánh giá trước

Cách Rules hoạt động

Quy tắc quan trọng:
  • Không có rules → Forward TẤT CẢ email
  • Có rules → Đánh giá theo priority (số nhỏ trước)
  • Rule match đầu tiên thắng → thực hiện action của rule đó
  • Không match rule nào → Ignore (chế độ whitelist)
💡 Lưu ý: Khi bạn tạo rules, hệ thống chuyển sang chế độ whitelist. Chỉ email match rule có action "Forward" mới được gửi qua Discord. Còn lại bị bỏ qua.

Ví dụ Filter Rules

Ví dụ 1: Chỉ forward email từ sếp

Name: Boss emails Field: From Operator: Contains Value: boss@company.com Action: Forward Priority: 1

Ví dụ 2: Bỏ qua email marketing (promotions)

Name: Skip promotions Field: Label Operator: Equals Value: CATEGORY_PROMOTIONS Action: Ignore Priority: 0 ← đánh giá trước rule khác

Ví dụ 3: Forward email có "urgent" trong tiêu đề

Name: Urgent emails Field: Subject Operator: Contains Value: urgent Action: Forward Priority: 2

Ví dụ 4: Multi-condition — Email từ domain cụ thể VÀ có keyword

Name: Important partner emails Conditions: 1. Field: From | Operator: Contains | Value: @partner.com 2. Field: Subject | Operator: Contains | Value: invoice Logic: All (AND) ← cả 2 điều kiện phải match Action: Forward Priority: 1

Xử lý lỗi

LỗiNguyên nhânCách fix
Test Connection failed Bot token sai hoặc bot chưa được invite vào server Kiểm tra token, invite lại bot
Cannot access channel Bot không có quyền trong channel Kiểm tra bot permissions trong server settings
Watch Start failed Gmail API chưa enable hoặc Pub/Sub topic chưa tạo Enable Gmail API, tạo topic trên GCP
Watch Expired Watch hết hạn 7 ngày, renewal cron thất bại Click "Start" lại, kiểm tra Gmail token
Email không forward Filter rule chặn hoặc không match Kiểm tra rules, thử tắt tất cả rules (forward all)
Duplicate messages Pub/Sub gửi lại message Bình thường — hệ thống tự dedup
